TENT in H1 is now tent_v2. EATA, SAR and CoTTA in the secondary comparisons are now eata_v2, sar_v2 and cotta_v2. These are event-wise binary segmentation adaptations for Sentinel-1 VV/VH. Each adapter resets to the source checkpoint for each activation, adapts without target labels for 200 steps on batches of eight random 256 × 256 crops (smaller if required by the chips), and scores chips after adaptation without further optimizer updates. Adaptation uses the fixed crop seed 0, rotations and horizontal flips, and source-training normalization. TENT, EATA and SAR update batch-normalization affine parameters with Adam at learning rate 0.001 and use batch statistics for adaptation and prediction. TENT minimizes pixel entropy. EATA uses a pixel entropy cutoff of 0.4 ln(2), cosine diversity margin 0.05, probability EMA decay 0.9, entropy weighting, and a source Fisher penalty with weight 2000. Fisher is estimated from 20 pseudo-labelled source-training crop batches with seed 1729. SAR uses the same entropy cutoff before and after a SAM perturbation of radius 0.05, entropy EMA decay 0.9, and a recovery threshold of 0.2 that resets model and optimizer state. CoTTA uses all-parameter Adam at learning rate 0.0001, a fixed source anchor, EMA teacher decay 0.99 and stochastic restoration probability 0.01. When mean anchor confidence is below 0.9, the teacher averages 32 spatially aligned logit views using invertible rotations and reflections plus a shared VV/VH offset sampled uniformly from −1.5 to +1.5 dB. The same confidence rule applies at prediction. EATA cosine margin 0.9 and SAR recovery threshold 0.2 ln(2)/ln(1000) are separate exploratory sensitivity analyses. Both are reported alongside their default versions without selecting a setting on held-out results.

## Justification

We are updating the protocol before accessing the held-out test data. A code audit found that the earlier TENT, EATA, SAR and CoTTA implementations differed in important ways from the published methods. We now specify corrected event-wise segmentation adaptations, identify the corrected TENT implementation for H1, and keep EATA, SAR and CoTTA in the secondary comparisons. The earlier results remain documented under their original implementation names. The Otsu dark-share statistic used label-valid support, and development data did not yield a defensible visibility cutoff. We therefore withdraw H6 from confirmatory testing, retain H1–H5 with Holm adjustment across five tests, and retain the Otsu analysis as exploratory. We also remove the Prithvi-EO-2.0 fallback because a compatible Sentinel-1 input protocol has not been established for it. These changes were motivated by the audit and existing development data.
