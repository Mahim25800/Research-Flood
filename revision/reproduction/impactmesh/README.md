# PX1 ImpactMesh reproduction materials

This archive contains the original single-date protocol snapshot, the metadata and checksums for its recorded predictions, and the analysis code. The follow-up records contain the verified darkness-only and backbone crossover results, the independent TG-TTA port's frozen protocol and verified results, and the matched false-alarm analysis by activation and seed. `SHA256SUMS` pins the archive members and the nested baseline snapshot retains its original manifest.

The manifest and summary reports support an audit of the study design and reported numbers. Recomputing metrics or running inference requires the referenced radar inputs, labels, checkpoints or saved score arrays. Those binaries are outside this metadata archive. The archived run notes identify the exact data inputs and file hashes expected by the verification scripts. Publication of this archive alone does not give access to private Kaggle jobs or the local score audit.
